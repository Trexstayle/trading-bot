## معرفی

هر معامله‌ی خوب از سه سؤال تشکیل می‌شود: **کجا** منتظر بمانیم؟ **چطور** وارد شویم؟ و **با چه ریسکی** معامله را مدیریت کنیم؟

Z-P-S به‌جای اینکه همه‌ی این تصمیم‌ها را در یک کد پیچیده ادغام کند، سیستم معاملاتی را به **سه موتور مستقل** تقسیم می‌کند. هر موتور فقط یک مسئولیت دارد و خروجی استاندارد خودش را به موتور بعدی می‌دهد. نتیجه این است که هر بخش جداگانه قابل تست، بهبود و جایگزینی است.

## معماری سیستم

```mermaid
flowchart LR
    A["🎯 استراتژی<br/>کجا؟"] --> B["🔫 ستاپ<br/>چطور؟"] --> C["📋 پلن<br/>با چه ریسکی؟"]
```

| موتور | تعریف | وضعیت |
|:--|:--|:--:|
| 🎯 **استراتژی (Strategy)** | لول و سطحی است که می‌شود روی آن منتظر تشکیل ستاپ بود و روی آن سطح، با ستاپ موردنظر انتظار ترید داشت. | ✅ ساخته‌شده |
| 🔫 **ستاپ (Setup)** | تکنیک و روش ورود ما روی استراتژی. شامل ستاپ شکست و ستاپ خط موازی. | 🚧 در حال توسعه |
| 📋 **پلن (Plan)** | نحوه‌ی مدیریت ترید: میزان ریسک روی هر معامله، حجم، حد ضرر، حد سود و مدیریت سرمایه. | 🚧 در حال توسعه |

## موتور استراتژی

موتور استراتژی سطوح قابل معامله را از روی ساختار قیمت استخراج می‌کند. این کار در سه مرحله انجام می‌شود:

```mermaid
flowchart LR
    D["کندل‌ها<br/>(CSV / MT5)"] --> E["ATR سفارشی"] --> F["ZigZag"] --> G["طبقه‌بندی پیوت‌ها"]
```

### ۱. ATR سفارشی (`atr.py`)

مقیاس همه‌ی فاصله‌ها در سیستم، ATR است. به‌جای ATR ساده، از میانگین چند دوره‌ی بلندمدت استفاده می‌شود تا عدد پایدارتر باشد و با اندیکاتور متاتریدر هم‌خوانی داشته باشد.

| تایم‌فریم | فرمول |
|:--|:--|
| M5، M15، H1 و سایر | `(ATR55 + ATR89 + ATR264) / 3` |
| W1 | `(ATR22×1.028 + ATR55 + ATR89 + ATR178×0.94) / 4` |
| MN1 | `(ATR24×1.01 + ATR55×0.97 + ATR89×0.93) / 3` |

اگر کندل کافی برای فرمول اصلی وجود نداشته باشد، سیستم به `ATR14` برمی‌گردد تا محاسبات متوقف نشود.

### ۲. ZigZag (`zigzag.py`)

پورت خط‌به‌خط از اندیکاتور `Pivot Trex.mq5`. یک پیوت زمانی **تأیید** می‌شود که قیمت **بسته‌شدن** کندل به اندازه‌ی `ATR × ضریب` از سقف یا کف کاندید فاصله بگیرد. الگوریتم سه فاز دارد:

1. پیدا کردن پیوت شروع در بازه‌ی ۵۲۸ کندلی نزدیک قدیمی‌ترین داده
2. حرکت به سمت جدیدترین کندل و تأیید پیوت‌ها
3. افزودن **پیوت کاندید** (آخرین پیوت که هنوز تأیید نشده و ممکن است جابه‌جا شود)

> حداقل ۲۷۰ کندل لازم است؛ در غیر این صورت خروجی خالی برمی‌گردد.

### ۳. طبقه‌بندی پیوت‌ها (`pivot_classifier.py`)

هر سه پیوت متوالی (P1، P2، P3) بررسی می‌شود و پیوت وسط (P2) طبقه‌بندی می‌شود. دو اندازه‌ی کلیدی (به درصد ATR) داریم: `l1pct` فاصله‌ی P1 تا P2 و `l2pct` فاصله‌ی P2 تا P3. شرط `has_close` هم می‌گوید در بازه‌ی P2 تا P3 حداقل یک کندل با قیمت بسته‌شدن ۱۰۰٪ ATR دورتر از P2 وجود داشته است یا نه.

| نوع | l1pct | l2pct | has_close | مفهوم |
|:--:|:--:|:--:|:--:|:--|
| **Std** | ۲۴۰ تا ۴۰۰ | ۱۰۰ تا ۲۴۰ | لازم | ناحیه‌ی استاندارد |
| **Rev** | ۲۴۰ تا ۴۰۰ | ۲۴۰ تا ۴۰۰ | — | برگشت روند |
| **Trnd** | ۲۴۰ تا ۴۰۰ | ۴۰۰ به بالا | — | ادامه‌ی روند قوی |
| **Liq** | ۴۰۰ به بالا | ۱۰۰ تا ۲۴۰ | لازم | شکار حد ضرر (لیکوییدیشن) |

پیوتی که با هیچ‌کدام از این شرط‌ها نخواند، حذف می‌شود.

## ساختار پروژه

| فایل | وظیفه |
|:--|:--|
| `atr.py` | محاسبه‌ی ATR سفارشی |
| `zigzag.py` | الگوریتم ZigZag و استخراج پیوت‌ها |
| `pivot_classifier.py` | طبقه‌بندی پیوت‌ها به Std / Rev / Trnd / Liq |
| `data_loader.py` | خواندن کندل‌ها از CSV متاتریدر و تشخیص خودکار ترتیب زمانی |
| `candles_export.csv` | نمونه‌ی ۵۰۰ کندل M5 طلا (خروجی متاتریدر) |
| `atr_export.csv` | ATR هر دوره و ATR سفارشی از اندیکاتور، برای مقایسه با پایتون |
| `pivots_export.csv` | پیوت‌های اندیکاتور همراه با نوعشان، برای مقایسه با پایتون |

فایل‌های `*_export.csv` «پاسخ درست» اندیکاتور هستند؛ خروجی پایتون باید با آن‌ها یکی دربیاید.

## قرارداد داده

در تمام پروژه ترتیب کندل‌ها **جدیدترین اول** است:

```python
candles[0]   # جدیدترین کندل
candles[-1]  # قدیمی‌ترین کندل
```

هر کندل یک دیکشنری با کلیدهای `time` یا `datetime`، `open`، `high`، `low` و `close` است. تابع `load_mt5_csv` ترتیب را خودش از روی تاریخ تشخیص می‌دهد و در صورت نیاز معکوس می‌کند.

## نمونه‌ی استفاده

```python
from data_loader import load_mt5_csv
from atr import custom_atr
from zigzag import calculate_zigzag
from pivot_classifier import classify_pivots

candles = load_mt5_csv("candles_export.csv")
atr     = custom_atr(candles, tf="M5")
pivots  = calculate_zigzag(candles, atr, atr_multiplier=1.0)
result  = classify_pivots(pivots, candles, atr)

for r in result:
    p = r["pivot"]
    print(r["type"], p["price"], r["l1pct"], r["l2pct"])
```

هر آیتم خروجی شامل `pivot`، `type`، `l1pct`، `l2pct`، `has_close` و `atr` است.
